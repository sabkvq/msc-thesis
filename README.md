**Тема:** Информационная сложность аппроксимации многопараметрических гауссовских полей

## Описание исследования

Работа посвящена анализу информационной сложности аппроксимации многопараметрических гауссовских случайных полей. Предполагается исследовать зависимость минимального количества линейной информации, необходимой для достижения заданной точности, от размерности, погрешности и ковариационной структуры поля.

Ключевая величина — информационная сложность $n_d(\varepsilon)$. Для аппроксимации в среднем с абсолютным среднеквадратическим критерием и произвольной линейной информацией она определяется через собственные числа ковариационного оператора:

$$
n_d(\varepsilon)=\min\left\{n\ge 0:\sum_{k=n+1}^{\infty}\lambda_{d,k}\le\varepsilon^2\right\}.
$$

**Цель:** исследовать оценки и асимптотическое поведение $n_d(\varepsilon)$, а также условия трактабильности для выбранного класса полей. Конкретный класс и постановка будут уточнены совместно с руководителем.

**Предполагаемые методы:** функциональный анализ, спектральная теория ковариационных операторов, разложение Карунена — Лоэва, теория вероятностей, асимптотический анализ и тензорные произведения.
